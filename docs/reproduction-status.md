# 复现状态与证据边界

## 当前可用范围

本仓库提供模块源码阅读、测试平台和 EDA 流程参考，以及既有图表展示。它不是一套依赖齐全的可直接执行工程。

## 待补文件

综合脚本 `syn_chip_fixed_v2.tcl` 要求下列独立源文件，现有材料中没有保存：

- `cim_controller.v`
- `cim_top.v`
- `cim_array.v`
- `cim_chip.v`
- `posit_cim_storage_wrapper.v`

部分测试平台定义了同名行为存储 wrapper；这不能证明已具备综合流程所需的独立实现。部分流程还引用消融顶层或其他辅助脚本，需按所选流程补齐。

MNIST 测试平台依赖 `testdata/*.hex`。分析脚本依赖能耗/面积结果表，例如 `results/energy_workloads/trend_tables/01_dense_to_sparse_summary.tsv` 等。这些输入没有包含在当前材料中。

## 环境前提

历史脚本涉及 Synopsys DC、VCS、PrimeTime/PrimePower 以及 Cadence Innovus。工艺配置面向 TSMC 28 nm HPC+。需要自行提供适用的工具许可、授权标准单元与寄生参数库，并检查工具版本和命令兼容性。仓库不提供上述商业工具、工艺数据或许可。

公开副本中的服务器目录已替换为 `/path/to/projects`、`/path/to/licensed_pdk`、`/path/to/eda_tools` 等占位路径；部分 Tcl 中使用固定字符串赋值，仅设置环境变量不一定足够。还需按原脚本要求准备工作目录与输入文件。

`scripts/eda/clean_periods.tsv` 是待填写的配置示例，数值来自原文件中的占位值，不构成最终 timing-clean 证据。

## 历史报告与本次检查

论文摘要报告的验证范围为：16 核芯片多工艺角逻辑综合和门级仿真；单核运算核后端与负载级功耗评估。摘要中的单核能效为 POSIT⟨16,2⟩ 0.07965 TFLOPS/W、POSIT⟨8,2⟩ 0.1491 TFLOPS/W。

2026-10-22 归档检查已完成：95 个来源文件与公开副本对应检查、22 个相对文档链接检查、5 个 Python 文件语法解析和 `--help` 入口检查、38 个 Shell 文件的 `bash -n` 语法检查，以及全部 12 张精选图的人工视觉检查。公开文本已检查个人服务器路径和常见凭据模式。

帮助入口在 Python 3.12 环境及 NumPy 1.26.4、pandas 3.0.1、Matplotlib 3.9.2 下可用。当前环境对可选加速包 numexpr/bottleneck 版本给出警告；这次没有修改依赖，也未验证分析脚本的完整数据处理兼容性。

没有进行 RTL 功能仿真、逻辑综合、布局布线、时序/功耗分析或图表结果重算。语法与帮助入口通过不代表完整工程或实验通过。

第三方参考论文中的 83.23 TFLOPS/W 等结果不属于本毕设实测，未纳入本仓库的原创成绩陈述。
